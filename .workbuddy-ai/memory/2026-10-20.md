- 本机 git 全局代理 `127.0.0.1:2289` 已死；环境变量代理 `127.0.0.1:6921` 只放行 `api.github.com`，
  **`github.com` 不通** → `git push` 走 HTTPS 必失败。
- `gh` 能用（走 API），所以 `gh repo create` / `gh pr create` 正常。
- 解法：**SSH 通道**。`ssh -T git@github.com` 能连但没公钥；
  `gh ssh-key add` 需要 `admin:public_key` scope（没有）→ 改用 **部署密钥**：
  `gh api repos/<owner>/<repo>/keys -X POST -f key="$(cat x.pub)" -F read_only=false`
  然后 `GIT_SSH_COMMAND="ssh -i ~/.ssh/id_ed25519_blacktide"` + remote 改 SSH，推送成功（120MB / 25s）。

`.gitignore` 排除了 `_source/ _build/ _shots/ build/*.exe .godot/`；
