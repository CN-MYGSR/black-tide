黑潮行动 / Operation Black Tide
================================

开放世界 PvPvE 军事撤离射击 · Godot 4.7.2

运行
----
双击 BlackTide.exe。首次启动会生成世界，约 2~4 秒黑屏是正常的（在生成地形和铺据点）。
需要支持 Vulkan 的显卡（GT 1030 及以上即可）。

操作
----
WASD      移动
Shift     冲刺（消耗体力）
Ctrl / C  蹲下
空格      跳跃 / 倒地时按住可延缓失血
鼠标左键  射击
鼠标右键  瞄准
R         换弹
1 / 2     主武器 / 副武器
F         交互（搜刮补给 / 救起队友 / 登机撤离）
4 / 5 / 6 绷带 / 敷料 / 维生素
G         呼叫撤离直升机
V         第一人称 / 第三人称切换
N         夜视仪开关（需要先在装备页购买）
F         靠近载具时上车 / 下车
Esc       释放鼠标
回车      结算后重开

一局怎么玩
----------
0. 主菜单里先在「军械库 / 装备 / 载具」花钱配好装，再点「开始行动」。
1. 在「铁砧前线基地」落地，身边有 3 名友军跟随。基地南面有大门，别绕圈找出口。
2. 左上角给出目标：夺取某个敌方据点。
3. 横穿岛屿，会遇到武装分子（红）和第三方小队（敌对所有人）。
4. 进入据点圆圈内、清掉守军，控制进度 0→100% 即易主。
5. 目标完成后按 G 呼叫直升机，14 秒后降落，靠近按 F 登机结算。
6. 阵亡会损失 25% 信用点。

存档
----
